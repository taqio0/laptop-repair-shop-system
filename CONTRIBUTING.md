# Contributing

- Work on a branch and open a pull request.
- Branch names: `feature/SCRUM-<ticket>-short-name`, `fix/SCRUM-<ticket>-short-name`.
- Commit messages start with the Jira key: `SCRUM-<ticket> describe the change`.
- A pull request needs one review from another team member and a passing CI run once automated checks are configured.
- Move the Jira ticket to In Progress when you start and to Done when the pull request is merged.
