# Contributing

- `main` is protected. Work on a branch and open a pull request.
- Branch names: `feature/LRS-<ticket>-short-name`, `fix/LRS-<ticket>-short-name`.
- Commit messages start with the Jira key: `LRS-36 add POST /orders`.
- A pull request needs one review from another team member and a passing CI run.
- Move the Jira ticket to In Progress when you start and to Done when the pull request is merged.
